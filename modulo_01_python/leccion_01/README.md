# 🐍 Lección 01: Hola Mundo, Variables y Tipos de Datos

## 1\. Imprimir mensajes en pantalla

Para mostrar texto en la consola usamos `print()`:

```
print("¡Hola! Estoy aprendiendo Python desde cero.")

```

## 2\. Guardar datos en "cajitas" (Variables)

Una variable es un nombre que le das a un valor para guardarlo en la memoria de la computadora.

```
nombre = "Tomás"
edad = 25
precio_dolar = 1250.50
es_estudiante = True

```

## 3\. Tipos de datos básicos

* **str** **(String / Texto)**: Se escribe siempre entre comillas. Ej: `"Data Engineer"`
* **int** **(Entero)**: Números sin decimales. Ej: `25`, `-10`
* **float** **(Decimal)**: Números con punto decimal. Ej: `100.50`
* **bool** **(Booleano)**: Verdadero o Falso. Solo puede ser `True` o `False`.
